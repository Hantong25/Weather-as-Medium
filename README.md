# Ephemeral — 概念 3D 展示 · 2026.10.19.2

当前概念：A0 天幕（0.841 × 1.189 m）水平悬于上方，底面承接投影；下方为 700 × 700 mm 正方形木质框架，由 pond liner 包裹防水，四周摆放砖块作边缘装饰，框内填充迷你黑色石块构成地形，加水形成水洼。水位固定，不再使用水位变化交互；投影画面沿用此前设定。

双击 `Start Demo.command`，启动后保留终端窗口。需要 Python 3 和支持 WebGL 2 的现代浏览器；不要直接双击 HTML。英文入口：`python3 launch.py --lang en`。右上角版本标记应显示 `CONCEPT 3D · 2026.10.19.2`。

## 两个工作区

- **概念 3D 展示**：固定模型，不可编辑部件。拖动旋转、滚轮缩放，方向键与 + / − 亦可。视角预设：整体、观众视角（眼高 1.62 m、距水洼中心约 0.6 m）、水洼俯看、分层构造。可切换分层展开、标注、展厅照明（暗场／明亮），并调整天幕底面离地高度。右侧「构造清单」逐项标明哪些尺寸已定、哪些是模拟假设。
- **投影设定**：天空按「日出 → 晴天 → 日落 → 夜晚阴天 → 日出」循环。太阳沿墨尔本十月的真实轨迹连续移动（东南东升起，正午在北方约 59° 高，西南西落下），天色由大气散射计算：瑞利散射（蓝天）、米氏散射（太阳周围的白亮和浑浊）、臭氧吸收（暮光的蓝紫色），并随亮度自动调整曝光。云由阳光（低太阳时变红，日落后高空云仍短暂被照亮）、天光和夜间城市光照亮；夜里云层逐渐聚拢成阴天并出现雨声，黎明前散开、可见少量星星。四个时段默认等长（各 15 秒，一轮 60 秒，可在时间轴下方调整）；日出、日落两段全程处于最有色彩的高度（约 −6.6° 至 +9°），太阳在地平线附近放慢，全程不跳、不倒退。低角度阳光从侧面照亮云底，日出前后与日落前后云层呈粉、橙、金色。画面固定 24 帧：天色在两个预先算好的太阳位置之间逐帧混合，下一状态在后台分帧计算，早晚快速变色时也平滑。天色组合：「大气类型」6 种（墨尔本日常、雨后清透、海雾柔光、雾霾暖阳、山火烟尘、火山暮光〔近似〕）改变空气成分，颜色仍由散射计算；「调色」6 种（自然、暖调胶片、冷调清晨、梦幻粉紫、柔和粉彩、黑白银盐）叠加在最终画面上，可与任一大气类型组合，共 36 种。另有「大气浑浊度」微调与「夜间城市光」。云随墨尔本实时风整体飘移，云内纹理同速移动，云边生成与消散的速度比 10.12.2 慢一半。每朵云的上层各自朝一个随机方向收拢（10.16.2 及以前全部朝画面中心收拢，形成放射状）。一位观众对应一朵云：到来时在天幕空处渐显；云飘出天幕或约一两分钟后消散时，上风处生成一朵新形状的云；离开后渐隐。每次启动的云形不同。「倒影检查」显示观众绕水洼走动时看到的倒影。

投影设定的版面：播放进度在顶部；天空预览居左，右侧是画面、观众、大气、云形、风、雨声等实时参数，预览下方的标签页放倒影检查、时长、预设、摄像头与素材记录。电脑端窗口高度 ≥ 560 px 时整页不滚动，各面板内部滚动，调参时预览始终可见。

天幕底面直接显示同一实时天空（叠加光表现）。天空形状选「铺满屏幕」时覆盖整张 A0；圆形／方形时投在中央 841 mm 见方范围。投影机型号、位置与投射距离未定，模型中不绘制。

## 模拟口径

- 水洼轮廓由石块地形与固定水位决定，模拟约 42 × 41 cm；不模拟水位下降、岸线退缩、滴水或水流。
- 假设值：框高 150 mm、板厚 35 mm、砖 230 × 110 × 76 mm 两层干摆、石块粒径约 10–20 mm、中部下凹约 35 mm、天幕高 2.27 m（沿用前版默认）。
- 倒影亮度、水色与石块形态为视觉近似，未做光学或材料标定。

## 预设保存

在预览下方「参数预设」中点击「保存当前参数」保存天空、时间、人数和天幕高度等手动参数。「设为启动默认」可在重新打开时恢复。颜色预设单独保存。

预设文件独立于程序：`~/Documents/Ephemeral User Data/presets.json`，每次保存保留 `presets.previous.json`。旧版预设仍可载入：其中的天空与时间参数照常生效，旧建造部件和水洼参数保留在文件中但本版不显示。支持 JSON 导出和合并导入。`python3 launch.py --data-dir PATH` 可指定另一数据目录；测试须使用临时目录。
