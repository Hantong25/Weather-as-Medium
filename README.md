# Accumulus — 概念 3D 展示 · 2026.10.27.1

Accumulus 是装置 EPHEMERAL 的天空程序（2026-10-27 定名）。

当前概念：天幕水平悬于上方，底面承接投影；大小与位置在「天幕探索」中确定（内置默认仍为 A0 · 0.841 × 1.189 m）。下方为 1 × 1 m 正方形底座：黑色木框，两圈灰色铺路砖围出中间的黑色碎石区（约 0.58 × 0.58 m，按照片估计，可改）；加水后只有碎石区中间一块不规则的低处成为水面（外接约 0.42 × 0.38 m，可改），四周露出石子。水位固定，不使用水位变化交互；投影画面沿用此前设定。

双击 `Start Demo.command`，启动后保留终端窗口。需要 Python 3 和支持 WebGL 2 的现代浏览器；不要直接双击 HTML。英文入口：`python3 launch.py --lang en`。右上角版本标记应显示 `CONCEPT 3D · 2026.10.27.1`。

## 两个工作区

- **概念 3D 展示**：固定模型，不可编辑部件。拖动旋转、滚轮缩放，方向键与 + / − 亦可。视角预设：整体、观众视角（从倒影检查观众的眼睛看出去）、水塘俯看、分层构造、平面俯视。可切换分层展开、标注、展厅照明（暗场／明亮）。右侧「构造清单」逐项标明哪些尺寸已定、哪些是估计或假设。
- **天幕探索**：按平面镜反射计算观众在水塘里看到哪一块天花。可调天幕宽、深、底面离地高度和中心偏移，观众站位（四周、正面半圈、正面 90°、只在正面）、眼睛离水塘中心的最近／最远距离、最低／最高眼高，以及碎石区和水面尺寸。只有水面会映出天幕，覆盖率只按水面计算。面板给出各站位水面映出天空的最差与平均比例、映满所有站位所需的最小天幕（可一键套用）和不同高度下所需的天幕；3D 中用黄色标出观众会看到但没有投影的天花，地面圆点按站位着色，白线为倒影检查观众经水面边缘四点反射到天花的视线。天幕宽深同时决定「铺满屏幕」投影的画面比例。
- **投影设定**：天空按「早晨 → 白天 → 晚霞 → 星空夜晚」循环，默认每段 60 秒、一轮 240 秒。太阳沿墨尔本十月的真实轨迹移动（东南东升起，正午在北方约 59° 高，西南西落下），每段取其中一截：早晨是日出前后（约 −6.6° 至 +9°），白天是上午到下午（28°–59°），晚霞是日落前后（+9° 至 −8°），夜晚是晴朗的星空（太阳低于 −24°），满月在太阳对面照亮云的一侧。天色由大气散射计算：瑞利散射（蓝天）、米氏散射（太阳周围的白亮和浑浊）、臭氧吸收（暮光的蓝紫色），并随亮度自动调整曝光。云由阳光（低太阳时变红，日落后高空云仍短暂被照亮）、月光、天光和夜间城市光照亮；低角度阳光从侧面照亮云底，日出前后与日落前后云层呈粉、橙、金色。「时长与速度」里每段可单独启用或关闭（至少保留一段），时长 2–300 秒；每次换段的过渡从这一段「结束前」若干秒开始，到下一段开始后若干秒结束（默认各 10 秒，即段长的六分之一），起点和终点都可自由设定。下一段紧接在太阳轨迹上时，太阳平滑走过去，不跳、不倒退；中间有段落关闭（或只留一段）时，两段天空交叉淡化，不会快进穿过关闭的时段。快速 60 秒、自然 240 秒、缓慢 660 秒三个档位只改时长和过渡，不改启用状态。夜晚不再聚成阴天，循环中也不再自动播放雨声（雨声只在试听时播放）。画面固定 24 帧：天色在两个预先算好的太阳位置之间逐帧混合，下一状态在后台分帧计算，早晚快速变色时也平滑。天色组合：「大气类型」6 种（墨尔本日常、雨后清透、海雾柔光、雾霾暖阳、山火烟尘、火山暮光〔近似〕）改变空气成分，颜色仍由散射计算；「调色」6 种（自然、暖调胶片、冷调清晨、梦幻粉紫、柔和粉彩、黑白银盐）叠加在最终画面上，可与任一大气类型组合，「调色强度」可减弱（0 即不调色）。「画面风格」的「风格强度」减弱粉彩、水彩的笔触与纸纹。「分段颜色」为四段分别设定天空颜色、云亮部（阳光或月光照到的一面）颜色、云暗部（天光与城市光）颜色及各自强度，以及云的透明度、饱和度和星星亮度：颜色只改色相、不改亮度，强度为 0 时保持物理计算的颜色，过渡期间相邻两段的设置平滑混合。另有「大气浑浊度」「夜间城市光」「夜间月光」。「天幕朝向」把整片天空——太阳、风向和云——一起旋转：0° 时画面上方为北、东在左（仰视），在展厅里转到投影中的天空与真实方位一致即可（10.24.5 及以前旋转时太阳不动，另有「画面北向旋转」，现已合并）。云以恒定速度漂移和变形：「风与运动」中的漂移速度与形变速度全程不变，不随天气阶段或实时风速忽快忽慢；墨尔本实时风只决定方向，风向改变时约半分钟内平稳转过去。云内细丝匀速移动。控制窗口在后台时由 Worker 计时，纯投影窗口仍按原速收到更新。每朵云的上层各自朝一个随机方向收拢（10.16.2 及以前全部朝画面中心收拢，形成放射状）。一位观众对应一朵云：到来时在天幕空处渐显，随风飘过，完整飘出画面后才淡出；它开始飘出时，一朵新形状的云从对侧（上风处）画外飘入，各观众的云前后错开，不会排成一列；离开后渐隐。无风（漂移速度为 0）时，云约一两分钟后就地消散，再生成新云。「观众与画面」中的「云出现时间」（2–60 秒，默认 8 秒）和「云消失时间」（2–60 秒，默认 10 秒）设定观众到来、离开时云渐显、渐隐的时长；云就地形成用 1.25 倍出现时间，消散用 1.2 倍消失时间。默认值即此前的节奏，10.24.5 的单个「云出现／消失时间」预设会换算过来。每次启动的云形不同。「云形与质感」有 13 个滑条——形状：云团大小、轮廓扭曲、纹理尺度、团块感、立体纵深；厚度：云的浓度、背光暗部；边缘：边缘碎度、边缘侵蚀、边缘柔和、逆光银边、云团粘连、边缘凹凸幅度——以及 4 个起点：柔和 · 默认、丰富边缘（参考 10.06.3 的不规则硬边与灰色云芯）、浓厚积云、轻薄云丝。「云团粘连」调低时相邻的云各自成团，不再被拉出丝状连接（1 为此前的样子）；「边缘凹凸幅度」让轮廓出现圆润的鼓包和凹口（0 为此前的样子）。默认值画出的云与 10.19.2 相同；调好的云形和 13 项数值可单独存为「云参数」随时载入，也随参数预设保存，并同步到纯投影窗口。「云的区域」限定大云只在画面的某一块生成（中心、宽、高按画幅比例），大云按区域大小变小、集中；区域外的天空和背景薄云保持不变，整体仍是一片完整的天空，不画边框。新云从区域上风侧外渐渐凝结飘入，飘出下风侧后渐渐消散，「边缘羽化」设定这段距离（默认 30% 区域短边）；区域边缘与画面边缘重合时（默认整幅即如此），云完整飘出画面后才开始消散，新云也在画外凝结好再飘入。移动区域后，飘不进新区域的云渐隐，新云在区域里就地生成。「倒影检查」显示观众绕水洼走动时看到的倒影。

投影设定的版面：播放进度在顶部；天空预览居左，右侧是画面、观众、大气、云形、风、雨声等实时参数，预览下方的标签页放倒影检查、时长、预设、摄像头、投影映射与素材记录。电脑端窗口高度 ≥ 560 px 时整页不滚动，各面板内部滚动，调参时预览始终可见。

天幕底面直接显示同一实时天空（叠加光表现），云只出现在云的区域里。天空形状选「铺满屏幕」时覆盖整张天幕；圆形／方形时投在中央、边长等于天幕宽的范围。投影机型号、位置与投射距离未定，模型中不绘制。

## 摄像头人数识别

「摄像头」标签页一打开就列出全部摄像头，包括有线连接的 USB 摄像头；插拔后列表自动刷新，允许摄像头权限后显示设备名称。选择记在本机，下次启动沿用。识别用 YOLOX-tiny 人体模型（OpenMMLab 按 COCO 与 Human-Art 训练，正面、背面、侧面的站立人体都能识别），由 ONNX Runtime Web 在后台线程运行，本机（M1 Pro）约 0.2 秒一帧，不拖慢天空画面；默认最低置信度 50%。每秒检测一次（由后台计时，控制窗口在后台也不变慢）；人数取最近一段时间（「人数确认时间」，1–10 秒，默认 3 秒）检测结果的中位数，单帧漏检或误检不会让云闪现，人数变化约在这段时间过半后生效。在同一批网上找的背面、侧面和人群照片上，它比原来的 COCO-SSD 检出更多（5 个背影：原来 4 个、现在 5 个；卢浮宫人群：原来 2 个、现在 9 个）。画面里的人物画、海报也可能被算作观众，可用「检测范围」排除。只读取人数，不保存画面。

## 投影映射

投影机放在侧面下方斜向上投时，用四角映射（类似 TouchDesigner 的 corner pin）让画面不变形、刚好铺满天幕：

1. 打开纯投影窗口，拖到投影机所在的扩展显示器，双击全屏（Esc 退出）。纯投影窗口里没有任何文字、按钮和鼠标指针，只有天空。
2. 点控制页顶部「投影映射」（或预览下方的「投影映射」标签里的「开始校准」）。天幕上出现测试网格和四个色点：1 红、2 黄、3 绿、4 蓝（1 = 画面左上），不显示文字。
3. 在控制页的映射面板里，左框代表投影机画面：把 1–4 号角拖到使天幕上的色点落在天幕四角；点选一个角后方向键微调 1 个投影像素（Shift 为 10）。网格应呈正方形、圆应是正圆。想确保边缘不漏，可把四角稍微拖出天幕外。
4. 点「完成校准」，网格消失。「四角复位」回到居中的起始框，「关闭映射」恢复原来的铺满窗口。四角自动保存。

映射按天幕宽深比绘制天空，再用一次透视变换（homography）贴到四个角上；天幕是平面时，这正好消除斜投造成的梯形和透视变形，所以投到天幕上的云保持正常形状，不需要另外生成“反向变形”的云。前提是画面比例与天幕一致：映射面板里的天幕宽、深（与「天幕探索」同步）要填实际尺寸，正方形天幕两者相同，天空形状用「铺满屏幕」；比例不对时云会被拉伸。四角存在 `~/Documents/Ephemeral User Data/mapping.json`（上一份为 `mapping.previous.json`），与参数预设分开，重启后仍在。只校正平面上的形状；天幕下垂、对焦和远近亮度差不在校正范围内。纯投影窗口的四边形外为黑色，天幕外不出光。

## 模拟口径

- 水面为碎石区中间一块不规则静水（形状为示意），四周石子高出水面；不模拟水位下降、滴水或水流。天幕探索假设水面完全平静、天幕水平、眼睛为一点，不计头部和身体遮挡。
- 假设值：木框高约 60 mm、板厚约 30 mm，铺路砖约 200 × 100 × 50 mm 两圈，水面离地约 50 mm，水面以外的碎石面约高出水面 8 mm，天幕高 2.27 m（沿用前版默认）。
- 倒影亮度、水色与石块形态为视觉近似，未做光学或材料标定。

## 预设保存

在预览下方「参数预设」中点击「保存当前参数」保存天空、时间、人数和天幕高度等手动参数。「设为启动默认」可在重新打开时恢复。云参数在「云形与质感」中单独保存。存过云参数后，预设文件升为第 3 版；更早的程序版本会拒绝读取并保留文件不动，不会丢失云参数。

预设文件独立于程序：`~/Documents/Ephemeral User Data/presets.json`，每次保存保留 `presets.previous.json`。投影映射的四角不随参数预设保存，单独存在同一文件夹的 `mapping.json`。旧版预设仍可载入：其中的天空与时间参数照常生效，旧建造部件和水洼参数保留在文件中但本版不显示。循环各段的启用、时长、过渡，分段颜色，风格、调色强度与月光，云出现／消失时间也随参数预设保存；10.24.5 能读取本版预设（只认识其中旧有的字段）。支持 JSON 导出和合并导入。`python3 launch.py --data-dir PATH` 可指定另一数据目录；测试须使用临时目录。
